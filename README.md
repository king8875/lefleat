# 리플렛마스터 — 메인(견적 구성) 페이지 시안

팀 내부 검토용 퍼블리싱 시안입니다.

- **레이아웃/인터랙션 기준**: [apple.com/kr/shop/buy-mac/macbook-air](https://www.apple.com/kr/shop/buy-mac/macbook-air)
  좌측 스티키 미리보기 + 우측 옵션 선택 리스트, 상단 고정 가격 바, 하단 견적 요약, FAQ 아코디언 구조를 그대로 따랐습니다.
- **헤더 / 푸터**: [leaflet.ai.kr](https://leaflet.ai.kr/) 실서버 마크업과 동일 (`front.css`, `leaflet.css`, `favorites.css` 원본 사용)
- **견적 선택 항목**: `lfleat-list.docx` 의 「견적 입력 요소」 표 01~10 그대로 반영

## 진행 방식 (단계형)

- 좌측 미리보기 영역(`.cfg-visual`)은 **sticky** 로 고정되어, 우측 항목을 내려가며 선택하는 동안 계속 보입니다. 판형에 따라 미리보기 뷰(앞면/뒷면/접었을 때)가 달라집니다.
- 미리보기 아래에 견적 요약 바(`.cfg-localnav`)가 붙고, 그 아래가 선택 내역(`.cfg-visual__meta`)입니다.
- 우측 항목은 **앞 단계를 선택하지 않으면 다음 단계가 잠깁니다.** 잠긴 섹션은 흐리게 처리되고 입력이 `disabled` 되며 “이전 단계를 먼저 선택해 주세요.” 문구가 표시됩니다.
- 한 단계를 선택하면 **다음 단계로 부드럽게 스크롤**됩니다. 마지막 단계(납기)를 고르면 하단 견적 요약으로 이동합니다.
- 아직 남은 단계가 있으면 요약에 `구성 중`과 남은 단계 목록이 표시되고 「이 구성으로 견적 신청」은 남은 단계로 이동시킵니다.

## 파일 구조

```
index.html                  메인 페이지
assets/css/config.css       이 페이지 전용 스타일 (.cfg- 프리픽스, 기존 CSS와 충돌 없음)
assets/js/config.js         견적 상태 관리 · 금액 계산 · 미리보기 렌더 · 단계 잠금 · 견적서 이미지 생성
assets/css/front.css        실서버 원본
assets/css/leaflet.css      실서버 원본 (헤더/푸터/공통 토큰)
assets/css/favorites.css    실서버 원본
assets/js/mouse-orb.js      실서버 원본
assets/img/                 로고
```

## 로컬 확인

```bash
python3 -m http.server 8899
```

`http://localhost:8899/` 접속. (CSS 안의 폰트는 jsdelivr CDN 을 사용하므로 온라인 상태에서 확인하세요.)

## 견적 항목

| 순번 | 항목 | 구현 |
|---|---|---|
| 01 | 판형 | 단면/양면 낱장 A4 · 2단 · 3단 · 4단 접지 · 선택 즉시 좌측 미리보기 반영 · **5단 이상은 견적문의 링크** |
| 02 | 수량 | 10 / 20 / 30 / 100 / 500 / 1,000 / 1,500 / 2,000부 구간별 단가 · **2,000부 이상은 견적문의 링크** |
| 03 | 용지 | 일반지 / 고급지 · 그람수(평량)는 미구현 상태를 안내 문구로 표기 |
| 04 | 후가공 | 복수 선택(없음 / 표지코팅 / 에폭시) · ‘없음’ 선택 시 나머지 자동 해제 |
| 05 | 작업 파일 제공 | 제공 선택 시 금액 추가 · **받을 이메일 입력**(유효한 주소를 넣어야 다음 단계로 진행) |
| 06 | 납기 | 일반(영업일 10일) 또는 **원하는 날짜 선택** · 남은 영업일로 단축 일수·급행 요율 자동 계산, 3영업일 초과 단축은 별도 문의 |

`lfleat-list.docx` 의 진행 기관 · 제본 방식 · 코팅 · 스타일 단계는 팀 검토 결과 이 시안에서 제외했습니다.
(코팅은 후가공의 ‘표지코팅’ 으로 통합)

## 하단 버튼

- **이 견적으로 결제하기** — 남은 단계가 있으면 해당 단계로 이동시킵니다.
- **견적서 이미지 저장** — 선택 내역·금액을 캔버스로 그려 PNG 로 내려받습니다. (외부 라이브러리 없이 동작)

## 단가에 대한 메모

금액은 **시안용 예시 단가**입니다. 기본 구성(3단 접지 · 500부 · 일반지 · 후가공 없음)이
실서버 안내 문구인 `110만원(VAT 포함)`에 맞도록 맞춰 두었습니다.
실제 단가표가 확정되면 `assets/js/config.js` 상단의 `PRICE` 상수와
`index.html` 각 카드의 `data-price` / `data-unit` / `data-mult` 값만 교체하면 됩니다.

`?format=fold3&qty=500&paper=일반지&finish=표지코팅&file=제공 안 함&due=일반` 처럼
쿼리스트링으로 구성을 복원할 수 있습니다. (이메일은 개인정보라 링크에 담지 않습니다.)
